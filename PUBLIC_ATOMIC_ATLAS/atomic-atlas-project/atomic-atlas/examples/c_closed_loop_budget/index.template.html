Declared equations, assumptions & sources
Mass = B + V + C + D + R = 1
Stored energy E = U + 5(V + C)
Energy residual = E − Q_in + Q_out
Evaporation x = min(max(0,B−0.02), max(0,0.35−V), 0.08Δt,
                    max(0, U−B)/(5−1))
U ← U − 5x; B ← B−x; V ← V+x
Condensation: C → D; Q_out ← Q_out + 5Δm
Demo change = |return_base − return_cut| / |return_base|
Undefined if baseline return is approximately zero.

Project-proposed dimensionless equations, version ATLAS-C/1.0.0. Boiling threshold 1, vapour energy 5, zero-energy returning liquid, capped transfer rates, operator-split Δt=0.1 s. Heat exchange is explicit. Pressure, geometry, real temperature, materials, nucleation and fluid PDEs are absent. Time is a demo clock, not calibrated physical time.

Source: model.js and MODEL.md in this package. Project framing comes from the current Example 3 discussion. This standalone toy model does not import the Python core. Interpretation labels are not historical formula transcriptions.

Provenance ledger

Opening ledger…

Every receipt carries its previous hash, parameters, state, model version and step count. Verification re-simulates the history in a fresh state. New runs append; they do not erase earlier runs.

Browser-local persistence is best effort. Export receipts for durable recovery. Hashes detect altered chains relative to a retained head; they are not signatures or proof of source truth.

Restore is allowed only when this browser ledger is empty. Existing history is never replaced.

Standalone local demonstration · No network requests, telemetry, or connected LLM. File recovery and model replay are deterministic tests; language-model recall is untested. Open the HTML directly, or use a local server for a consistent browser storage origin.
