Open index.html for the offline synthetic retrieval comparison. Run python server.py for a loopback server and a NEW local SQLite database. No database or user events are shipped. The two methods share a corpus and 3800-character evidence cap. No LLM is connected, no performance improvement is measured, and this module is not yet integrated with the Python core. Pasted answers and subsequent exports may contain whatever you enter. Tests: python -m unittest discover -s tests -v; node tests/test_engine.js; node tests/dom_check.js. Full browser layout is untested.
