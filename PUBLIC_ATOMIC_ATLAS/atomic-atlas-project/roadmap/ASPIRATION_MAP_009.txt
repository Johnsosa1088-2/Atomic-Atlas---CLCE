HOW TO ADVANCE A PROPOSAL
Freeze a use case and inputs; define the domain adapter and measurable output; select an independent baseline; specify failure criteria; run held-out tests; append results with source and version hashes. Only the tested claim can advance. Failed or untested claims remain visible.

PRIORITY
Start with an offline retrieval evaluation: it is closest to Example B and can test the user's hypothesis that atlas organization improves LLM robustness. Use the same model, task set and source corpus, varying only retrieval organization. Measure attribution accuracy, unsupported claims, contradictions, task accuracy and retrieval overhead. No benefit is currently established.
