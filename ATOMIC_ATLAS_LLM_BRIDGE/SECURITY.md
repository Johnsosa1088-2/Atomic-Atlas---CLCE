# Security boundaries

Do not commit secrets, real conversation histories, private databases or generated packets. Examples and automated tests are synthetic.

This prototype is not hardened for hostile databases, unbounded input streams or multi-tenant deployment. Hash chains do not authenticate authors. Prompt instructions do not guarantee injection resistance. Citation validation does not establish semantic support.

Model proposals are data only and have no commit path. Review all proposed changes and domain constraints before developing any write integration. Do not post private data in public issues when reporting a problem.
